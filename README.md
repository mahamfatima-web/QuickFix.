# QuickFix - Home Services Website

## About
QuickFix is a responsive home services website designed to make booking and managing home services easier. Users can explore services, submit booking requests, and track their booking status.

## Features
- Responsive navigation bar
- Home services section
- Online service booking form
- Automatic booking ID generation
- Booking tracking system
- Admin booking status management
- Contact form
- Data storage using LocalStorage

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## Project Purpose
This project was developed to practice frontend web development, responsive design, JavaScript, DOM manipulation, and LocalStorage.
